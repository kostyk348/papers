    log line 17: VALID   ../../../../fabricessa/cache/scratch/runs-autobuild4/sint-memory-mcp-2026-10-16/report.json (subject=sint-memory-mcp, families=10, metric entries=52)
    log line 18: validated with: tools/refslint/target/release/refslint.exe report
    exit=0 (18 s)

History worth recording, because it shaped the final code: the first attempt at this test ended
`RUN UNCERTIFIED` and the reason could not be read, because the harness captured the wrapper's
stderr and discarded it. The final `find_refslint()` prints whatever the wrapper wrote (`cargo`'s
error, or its "[refslint] building …" notice) and, if no shell is reachable from Python at all,
falls back to running the wrapper's single command (`cargo build --release` in `tools/refslint`)
itself. Both mechanisms are documented in the docstring.
