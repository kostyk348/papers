# figures/

Deliberately empty of figures at version 0.1.0: this deliverable is structure, taxonomy,
protocol and a verified reference base, and no figure in it would be anything other than
decoration.

Planned figures, each of which must be generated by a script in `code/` (never drawn by hand)
once the data exists:

1. `taxonomy-map.pdf` — the seven systems of `taxonomy.md` §4 as a coverage matrix, generated
   from a table in the source (not retyped).
2. `protocol-flow.pdf` — the run procedure of `protocol.md` §4 as a flow: pin → generate stream
   → run repetitions → score → validate report → restart probe → adversarial stream.
3. `per-operation-profile.pdf` — the first real comparison (paper §6), one panel per operation,
   with confidence intervals, produced from validated `report.json` files only.

Rule for this folder, consistent with the rest of the paper: a figure may not be committed
before the script that produces it and the data it consumes are committed in the same change.
